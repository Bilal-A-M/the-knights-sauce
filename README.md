# The Knight's Sauce 🗡️

A tiny story-mode 2D platformer. The Kingdom of Flavoria has lost **The Legendary Sauce** — no one remembers what it actually is. You are Sir Crouton, last knight of the Dipping Order. Cross the Pantry Plains, brave the Fridge Caverns, storm the Sauce Keep, and discover the Sauce's true identity in the finale.

**Playthrough: ~5–10 minutes.** No installs, no dependencies — everything is one HTML file drawn on a `<canvas>`.

## Play

Open `the-knights-sauce.html` in any modern browser. That's it.

## Controls

| Key | Action |
| --- | --- |
| A / D or ← / → | Move |
| W / ↑ / Space | Jump |
| J / Enter | Sword attack |
| M | Toggle sound |

## Features

- 3 short levels + story screens, mini-boss finale, and a mystery reveal ending
- Stomp or sword rival condiments (Ketchup blobs, Mustard goblins)
- 3-heart health system, checkpoints, collectible herb sprigs
- Parallax backgrounds and Web Audio sound effects, all generated in code

*No spoilers — the Sauce's identity stays secret until the very end.*
